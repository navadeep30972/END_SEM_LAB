GIT BRANCHING AND MERGING PROJECT

FILES
- index.html: Website structure
- style.css: Website design
- script.js: Button interaction

HOW TO USE
1. Open this folder in VS Code.
2. Open index.html in a browser to view the website.
3. Open the VS Code terminal in this folder.
4. Run the Git commands from your assignment.

IMPORTANT
The heading in index.html is:
<h1 id="page-title">Welcome to My Website</h1>

Use this same heading line to create the merge conflict:
- In main, change it to: Welcome to Main Branch
- In feature-header, change it to: Welcome to Feature Branch

After merging, choose the final heading you want and remove Git's conflict markers.
